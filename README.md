# GlowMaintenance

Система режима технических работ для серверов Minecraft (Paper / Purpur / Folia 1.21+, Java 21).

## Возможности
- Мгновенное включение и выключение режима тех. работ командами без перезагрузки сервера.
- Автоматическая активация и деактивация серверного белого списка (WhiteList).
- Отключение всех игроков без права обхода (Bypass) при активации режима.
- Кастомный экран отключения с поддержкой корпоративных HEX-цветов.
- Динамический MOTD для списка серверов во время технических работ.
- Раздельные файлы конфигурации `config.yml` и сообщений `messages.yml`.

## Команды
- `/maintenance on` (или `/maintenance enable`) — включить режим тех. работ.
- `/maintenance off` (или `/maintenance disable`) — отключить режим тех. работ.
- `/maintenance toggle` — переключить текущее состояние.
- `/maintenance status` — узнать текущий статус тех. работ.
- `/maintenance reload` — перезагрузить конфигурацию и сообщения.

Алиасы команды: `/gm`, `/glowmaintenance`.

## Права
- `glowmaintenance.admin` — доступ к командам управления (по умолчанию: `op`).
- `glowmaintenance.bypass` — право входа на сервер во время тех. работ (настраивается в `config.yml`, по умолчанию: `op`).
